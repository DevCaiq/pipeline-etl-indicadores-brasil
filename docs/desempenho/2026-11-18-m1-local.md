## Keyset versus OFFSET

Foram comparadas as mesmas linhas nas duas estratégias, com LIMIT 101 para representar a consulta usada pela API ao servir páginas de cem itens. Dez EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON) por estratégia/posição, depois do HTTP; números abaixo são medianas do Execution Time em milissegundos.

| Posição | Deslocamento | Linhas SQL retornadas | Keyset ms | OFFSET ms | Blocos hit keyset / OFFSET na décima execução |
|---|---:|---:|---:|---:|---:|
| Início | 0 | 101 | 0,063 | 0,061 | 3 / 3 |
| Meio | 1200 | 101 | 0,062 | 0,3455 | 4 / 18 |
| Fim | 2500 | 14 | 0,038 | 0,676 | 3 / 32 |

Início e meio usaram Index Scan na pk_fato_serie. No fim, keyset usou Bitmap Index/Heap Scan e Sort em memória; OFFSET continuou percorrendo o índice desde o início. Na décima execução do fim, o Index Scan de OFFSET produziu 2514 linhas para descartar as primeiras 2500; keyset selecionou quatorze. Os planos reportaram zero Shared Read Blocks nessas execuções, coerente com buffers quentes. Não houve criação de índice ou alteração de configuração SQL.

O trabalho extra do OFFSET apareceu neste recorte, mas são tempos submilissegundo, em base pequena e aquecida. Não concluir custo absolutamente constante, ganho universal ou capacidade em um milhão de linhas. Não confundir Execution Time SQL com os percentis HTTP; a análise não identifica sozinha o gargalo de toda a aplicação.

## Alcance do resultado

A meta M1 de p95 <=500 ms e 5xx <1% foi atendida no total e nos quatro cenários, com zero falhas adicionais. Não é SLA de hospedagem, capacidade máxima ou garantia de latência em toda rota. A base é pequena; não houve repetição estatística independente, rampa de usuários, teste de carga concorrente com ETL nem leitura física fria. O limiar com cache de M2 não foi avaliado. Reconstrução pelo bronze teve duração registrada na etapa anterior, mas não foi promovida a benchmark ETL padronizado.

Próximo passo do M1: orquestração/agendamento local com recuperação e observação das execuções, além das pendências de homologação já documentadas. Não declarar M1 global concluído apenas com este resultado.
